\# Data Quality Reporting Tool



A reusable Python-based data quality profiling tool that analyzes CSV datasets and generates detailed quality reports. It helps identify missing values, duplicate records, invalid values, suspicious records, and dataset completeness.



\## Features



\- CSV dataset profiling

\- Missing-value detection

\- Duplicate-record detection

\- Unique-value analysis

\- Completeness calculation

\- Uniqueness calculation

\- Invalid age detection

\- Invalid salary detection

\- Email format validation

\- Suspicious-record identification

\- Automatic quality report generation

\- Automatic invalid-record report generation

\- Reusable for different CSV datasets



\## Technologies Used



\- Python

\- Pandas

\- NumPy
